Source attribution and modifications
====================================

The numeric sanitising/coercion algorithm used by the Kether actions derives
from Sponge's Coerce implementation via TabooLib:

- Project: TabooLib — https://github.com/TabooLib/taboolib
- Upstream path: common-legacy-api/src/main/java/taboolib/common5/Coerce.java
- Fixed revisions: 0e3a911fc55624075b5c9abd4368cb5b063b022b and
  34732f0a17aa3d739c8c7c1a3b3ff44c948f84f5.
- Changes: shared Kotlin coercion helpers targeting Java 8, with explicit
  ScriptContext services and no TabooLib runtime dependency.
